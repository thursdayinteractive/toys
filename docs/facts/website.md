# Website facts

- **fact-website-hosting.** ThursdayInteractive.com is on a GoDaddy basic hosting plan. The owner cannot edit the site's own text or source, but can embed content: per the site's own description, an embed injects HTML, CSS and JavaScript between the page's `<body>` tags. (verified: 2026-09-28)
- **fact-website-embed-frame.** The site's embeds run inside a frame, not in the page itself. In the owner's preview the test embed's frame was 1231 × 149 pixels, about the height of its content. (verified: 2026-09-28)
- **fact-website-embed-capabilities.** Inside an embed, embedded CSS applies, inline and module scripts run, browser storage works, secure random numbers are available, and a script hosted on another site loads and runs. (verified: 2026-09-28)
- **fact-website-embed-size.** A 2 KB embed ran in full. Embeds of 100 KB and 500 KB did not: the script at their end never ran, so the site cut them short or refused them. The same files ran in full in a browser outside the site. The exact limit is somewhere between 2 KB and 100 KB. (verified: 2026-09-28)
