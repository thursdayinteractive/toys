# Roadmap

## Now
Phase 1: Foundation and standalone. Stage: repository setup.
Active: [[bm-repository-foundation]].

## Phase 1: Foundation and standalone
Scope: The documentation system, the code tooling, the randomizer and dice roller cores, and the standalone host ([[DEC-260928-roadmap-phasing#clause-1]]). Every core meets the add-on constraint from its first version ([[§3]]). Not in this phase: the website, the curriculum app add-on, temporary removal of randomizer items, and storage.
- **bm-repository-foundation.** The documentation system is in place with its decision records accepted, and the code tooling runs a typecheck and tests on an empty core. Status: in progress.
- **bm-randomizer-core.** The randomizer core is built to [[§4]] and tested with a fixed randomness source, meeting [[§3]]. Status: not started.
- **bm-dice-roller-core.** The dice roller core is built to [[§5]] and tested with a fixed randomness source, meeting [[§3]]. Status: not started.
- **bm-standalone-host.** The randomizer and dice roller are usable as a standalone app. Status: not started.

## Phase 2: Website
Scope: The randomizer and dice roller on ThursdayInteractive.com, built on the Phase 1 cores without change.
- **bm-website-host.** The randomizer and dice roller are usable on ThursdayInteractive.com. Status: not started.

## Phase 3: Curriculum app add-on
Scope: The randomizer and dice roller added to the curriculum app, built on the Phase 1 cores without change.
- **bm-app-add-on.** The randomizer and dice roller are usable inside the curriculum app. Status: not started.
