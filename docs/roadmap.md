## Phase 1: Foundation and standalone
Scope: The documentation system, the code tooling, and the route by which any toy is delivered as a standalone app ([[DEC-260928-roadmap-phasing#clause-1]]). Not in this phase: website and curriculum app delivery.
Randomizer: the randomizer and dice roller cores, saved lists, and the toy in the standalone app. Not in this phase: temporary removal of items.
- **bm-repository-foundation.** The documentation system is in place with its decision records accepted, and the code tooling runs a typecheck and tests on an empty core. Status: done.
- **bm-standalone-delivery.** The standalone delivery route is decided and works for a toy's core without change to it. Status: not started.
- **bm-randomizer-core.** The randomizer core is built to [[randomizer§1]]–[[randomizer§4]] and tested with a fixed randomness source. Status: done.
- **bm-dice-roller-core.** The dice roller core is built to [[randomizer§5]] and tested with a fixed randomness source. Status: not started.
- **bm-randomizer-standalone.** The randomizer and dice roller are usable in the standalone app. Status: not started.

## Phase 2: Website
Scope: The route by which any toy is delivered on ThursdayInteractive.com.
- **bm-website-delivery.** The website delivery route is decided and works for a toy's core without change to it. Status: not started.
- **bm-randomizer-website.** The randomizer and dice roller are usable on ThursdayInteractive.com, built on the Phase 1 cores without change. Status: not started.

## Phase 3: Curriculum app add-on
Scope: The route by which any toy is added to the curriculum app.
- **bm-app-add-on-route.** The curriculum app add-on route is decided and works for a toy's core without change to it. Status: not started.
- **bm-randomizer-app-add-on.** The randomizer and dice roller are usable inside the curriculum app, built on the Phase 1 cores without change. Status: not started.
