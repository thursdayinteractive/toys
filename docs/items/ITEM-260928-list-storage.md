# Keep lists between uses

Lists start empty ([[DEC-260928-randomizer-weighting#clause-4]]). Storage comes later, as an adapter with no change to the core ([[§7]]). What is kept, where, and for how long is not yet decided.

## Done when
The owner has decided what is stored, and a list entered once is still there on the next use.
