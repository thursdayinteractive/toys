# What the standalone app is

The standalone host comes first ([[DEC-260928-roadmap-phasing#clause-1]]). The request says the toys can be "used independently as an app" but not what kind of app: a store-distributed mobile app, a web app opened in a browser, or something else. The answer decides the host's stack and how it is distributed.
