# How a toy enters the curriculum app

Every toy's core is built to fit the curriculum app ([[§3]]). The owner's current plan, 2026-09-28, which may change: toys are added separately within a course, the way modules are organized. How a toy's code reaches that app is decided in [[DEC-261001-toy-plug-in-contract]]: the toys' screens are built into the app as components, from one copy. That work is ahead of Phase 3, by owner direction; what is left here is the app's side and the website.

## Done when
The route is decided in a decision record here (done), and agreed in the curriculum app.
