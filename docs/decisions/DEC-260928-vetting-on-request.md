# Vetting on request

## Context

The documentation baseline made vetting standing conduct for changes many parts depend on ([[DEC-260928-documentation-baseline#clause-34]]). Full vetting, with independent agents, three candidate designs, a comparison and reviews, was sized for the curriculum app's shared mechanisms. The toys are small. The owner directed, 2026-09-28, that full vetting for a random picker is over-engineering.

## Clauses

- **clause-1.** **Vetting only when asked.** A change follows the vetting procedure ([[PROC-260928-vetting]]) only when the owner asks for it. Every other change is planned directly and brought to the owner for approval.

## Options considered

- **Vetting for every change many parts depend on.** Lost: by owner direction, it is too heavy for small toys.

## Precept conflicts resolved

- The vetting phrase of [[DEC-260928-documentation-baseline#clause-34]] is superseded by clause-1 (owner direction, 2026-09-28). The clause's other standing conduct stands.
