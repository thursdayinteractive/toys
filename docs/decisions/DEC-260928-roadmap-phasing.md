# Host order

## Context

Each toy is delivered to three hosts. The owner set the order in conversation, 2026-09-28.

## Clauses

- **clause-1.** **Order.** Standalone first, then the website, then the curriculum app add-on. The Roadmap's phases follow this order.
- **clause-2.** **Add-on compatibility from the start.** The app comes last in delivery order, but every toy's core meets [[§3]] from its first version, so the add-on does not need rework ([[DEC-260928-architecture-baseline#clause-3]]).

## Options considered

None. The order was set by the owner.

## Precept conflicts resolved

None found.

## Supersessions

- clause-1 is superseded, for the curriculum app host, by [[DEC-261001-toy-plug-in-contract#clause-4]]: that host is built now, ahead of the website, by owner direction. The Roadmap's phases are unchanged.
