# RogueLore colors and icons

## Context

The toys need colors and icons for their screens. The RogueLore colors and icons are held in the curriculum app's repository, `thursdayinteractive/curriculum-app`, which dropped Thursday Interactive branding in the RogueLore rebrand. The owner directed, 2026-09-28, that the toys use the RogueLore coloring and not Thursday Interactive branding. The standalone app's own files sit at the top of this repository, as the curriculum app's do ([[DEC-260928-standalone-app#clause-4]]).

## Clauses

- **clause-1.** **RogueLore, not Thursday Interactive.** Every toy's screens use the RogueLore colors and icons. Thursday Interactive branding is not used.
- **clause-2.** **Same paths as the curriculum app.** The colors are in `src/presentation/tokens.ts`, with the curriculum app's token names and values. Icons are in `assets/icons/` and the app icon files in `assets/`, under the curriculum app's file names.
- **clause-3.** **Which icons.** Icons that might apply to the toys are brought over: game icons, including the dragon and the dice; map icons; and navigation icons, including the chevrons. Export icons are not. More are brought over as screens need them.
- **clause-4.** **App icon.** The standalone app's icon is the RogueLore app icon, with the wizard character.

## Options considered

- **Thursday Interactive branding.** Lost: by owner direction, the toys use RogueLore's.
- **Only the icons a screen uses today.** Lost: by owner direction, every icon that might apply is brought over now.
