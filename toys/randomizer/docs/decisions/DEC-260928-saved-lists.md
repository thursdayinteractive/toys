# Saved lists

## Context

Lists were to start empty, with storage later and outside Phase 1 (clause-4 of [[DEC-260928-randomizer-weighting]]). The owner directed, 2026-09-28, that a list can be saved, in Phase 1. Storage goes through a storage adapter, and the core does not change ([[§6]]).

## Clauses

- **clause-1.** **What is saved.** A list is saved under a title the person chooses. The save holds each item's label and multiplier.
  amends: [randomizer§6]
- **clause-2.** **One list for now, room for more.** One saved list is enough for now. Saved lists are kept as an array of titled lists, so more can be kept later without changing how a list is saved.
- **clause-3.** **Phase 1.** Saving a list is part of Phase 1, delivered with the toy in the standalone app.

## Options considered

- **Storage in a later phase.** Lost: by owner direction, saving is needed now.

## Precept conflicts resolved

- clause-4 of [[DEC-260928-randomizer-weighting]] put storage later. Resolved by owner direction, 2026-09-28: this record supersedes that clause.
