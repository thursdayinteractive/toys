# Dice roller input rules

The owner asked for a simple numeric input for the number of sides. These questions are not yet answered:
- the smallest and largest number of sides allowed;
- what happens when the entry is not a whole number;
- the number of sides shown before the person enters one;
- whether one roll is always one die, or the person can roll several at once.

## Done when
The owner has answered each question, and the answers are recorded in a decision record.
